# Stage 17 — события, артефакты и UX карты

Stage 17 добавляет первый настоящий exploration layer поверх кампании и одновременно исправляет несколько проблем управления картой.

## Data-driven события POI

Шесть точек интереса получили одноразовые события первого посещения:

- Склад №2 — инвентаризация несуществующего Склада №1;
- Озеро Нормальное — совершенно нормальная вода;
- Подвал поликлиники 202 — кабинет 0.13 принимает;
- Секретные этажи физфака — красная кнопка без подписи;
- Временная застава — временный пропуск;
- Место, где почти нашли Корень — сувенирная лавка.

События описаны в `src/data/events/prototypeEvents.ts`. UI не содержит специальных ветвлений по id события. Первое посещение вызывает `triggerLocationEvent()`, выбранный вариант применяется через `resolveLocationEvent()`.

Состояние кампании хранит:

- `pendingEventId`;
- `resolvedEventIds`;
- `artifactIds`.

Поэтому событие нельзя повторно фармить после ухода/возвращения или после сохранения/загрузки.

## Артефакты

Добавлены шесть первых артефактов:

- Печать склада №1;
- Фляга совершенно нормальной воды;
- Талон к врачу на вчера;
- Красная кнопка без подписи;
- Временный ключ 1709 года;
- Почти-корень.

Артефакт остаётся в коллекции экспедиции. На этом этапе его `effects` являются эффектами находки: деньги, припасы, образцы и/или мораль.

### Владос

`artifact_effect_multiplier = 1.5` теперь реально используется. Численные эффекты найденного артефакта умножаются на коэффициент лидера при получении. Например Печать склада №1 даёт обычному лидеру +18 денег, Владосу +27.

Артефакты видны в разделе «Армия», а их количество — в campaign toolbar.

## UX карты

### Клик при приближении

Pan карты больше не начинается при pointer-down на `.map-node`. Узел останавливает pointer-down propagation, поэтому при любом zoom нажатие на город/POI снова активирует именно этот узел, а не захват камеры.

### Положение игрока

Текущий узел экспедиции теперь имеет:

- яркое двойное кольцо;
- пульсирующий halo;
- метку `ВЫ ЗДЕСЬ`;
- прежний треугольный маркер армии.

Это presentation-only состояние и не сериализуется.

### Завершение хода

Кнопка `Завершить ход` полностью удалена из `DecisionPanel`. Она всегда находится в отдельной постоянной панели между location/army dock и нижней навигацией. Панель также показывает, использовано ли стратегическое действие текущего хода.

## Save v9

Stage 17 поднимает save format до **v9**.

v8 → v9 добавляет пустые:

- `pendingEventId = null`;
- `resolvedEventIds = []`;
- `artifactIds = []`.

Старые v1–v8 мигрируют по существующей цепочке и не теряют владение городами, армии или распределение Орсии.

## Проверки

Проверено:

- все 6 событий ссылаются на существующие MapNode;
- все 6 artifact effects ссылаются на существующие артефакты;
- событие срабатывает только до разрешения;
- после разрешения повторный trigger не создаётся;
- Печать склада №1: +18 денег обычному лидеру и +27 Владосу;
- save v9 round-trip сохраняет артефакты/разрешённые события;
- legacy v8 мигрирует с пустым event/artifact state;
- весь TypeScript проект компилируется с временными декларациями отсутствующих npm-пакетов.
