# Stage 23 — актуальная карта, городские артефакты и директивы с поверхности

Stage 23 синхронизирует содержимое карты с утверждённой таблицей, добавляет одноразовую награду-артефакт за первое фактическое посещение каждого города и вводит первые утверждённые сюжетные сообщения руководства.

## 1. Карта синхронизирована с таблицей

Стабильные internal ids и topology графа не менялись, но пользовательские названия, описания и POI-события приведены к актуальной таблице.

Ключевые замены:

- `quiet-scream` → **Убежище 103**;
- `temporary-outpost` → **Неестественные джунгли**;
- `rival-post` отображается как **Канцелярские Копи**;
- **Великие хранилища столовой ГУМа** получили полное актуальное название;
- описания всех 21 узлов приведены к таблице;
- из описания Корня убран преждевременный спойлер про кафе.

## 4. Артефакт за посещение города

Каждый из 14 городов имеет один временно назначенный уникальный артефакт.

Правила:

- награда выдаётся только при фактическом нахождении основной армии в городе;
- срабатывает после завершённого перехода или успешного захвата;
- один город выдаёт награду только один раз за кампанию;
- повторные входы не фармят артефакты;
- города, переданные игроку событием Нацболов, не выдают артефакт до физического посещения;
- Владос усиливает численные эффекты городских артефактов тем же ×1,5;
- стартовая позиция сама по себе не считается новым посещением, поэтому артефакт Великих Нижних Выселок можно получить при последующем фактическом входе в город.

Распределение сделано один раз случайным образом при разработке и затем зафиксировано в data-файле. Оно не использует runtime RNG и не меняется между save/load.

## 5. Сюжетные директивы

Добавлена data-driven система коротких сообщений с поверхности. Состояние хранится в `CampaignState` через pending/resolved ids; React только показывает overlay.

Утверждённая последовательность:

1. после первого артефакта — сообщение об отличии экосистемы Орсии и требование собирать **артефакты**;
2. после расширения контроля минимум до 2 городов — сообщение Научного отдела про формы жизни с «выраженным запёком»;
3. после контроля минимум 3 городов — классификация по сохранению формы при 180–200 градусах;
4. после контроля минимум 4 городов — указание считать кости и пробовать костный мозг;
5. после разрешения события `almost-root-shop` — корректировка «послевкусия» на «остаточный сенсорный профиль»;
6. при попытке начать финальную операцию — требование собрать грибы и светящиеся ягоды, после подтверждения открывается обычный финальный выбор.

Первые пять сообщений идут строго по порядку: более позднее не перескакивает через неразрешённое раннее сообщение.
