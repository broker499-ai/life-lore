# Stage 30 — mobile-first campaign redesign

Application version: **0.30.0**  
Save format: **v17**

## Цель

Перестроить интерфейс кампании максимально близко к предоставленному mobile design-code, не меняя боевую математику перед будущим Battle 2.0.

## Кампания и мобильный UX

- Одна компактная шапка: лидер, состояние снабжения, меню и пять ключевых ресурсов.
- Индикатор гонки больше не занимает отдельную горизонтальную полосу и располагается поверх карты.
- Карта получает основную высоту телефона; нижний лист локации имеет ограниченную стабильную высоту.
- Действия города/маршрута/атаки больше не находятся в горизонтальном скролле.
- Все основные интерактивные элементы имеют touch target не меньше 44px по высоте; карта получила отдельные невидимые hit-targets для узлов.
- Однопальцевое перетаскивание работает с любого места карты, включая начало жеста на узле.
- Реализован настоящий двухпальцевый pinch-to-zoom с масштабированием относительно центра жеста.
- Колесо мыши масштабирует карту относительно курсора; кнопки +/- и центрирование сохранены.
- ViewBox учитывает фактическое соотношение сторон карты, поэтому на портретном телефоне SVG больше не превращается в маленький квадрат с пустыми полями.
- Разблокировка длинной второй части карты больше не заставляет камеру автоматически ужимать весь граф целиком.

## Fog of war

- Все города активной части карты с начала кампании показаны как известные поселения: видны название и положение, но не владелец, гарнизон, налог и актуальная обстановка.
- POI и специальные скрытые точки по-прежнему требуют разведки.
- Для каждой фракции фиксируется founding capital. Столицы показываются через fog of war вместе с известной принадлежностью и портретом лидера/фракции.
- Захват столицы не переписывает историческое знание о том, чьей столицей она была.
- Скрытая после ложного Корня вторая часть карты не раскрывается этим механизмом: её узлы физически не входят в активный граф до сюжетного события.

## Battle presentation

- Добавлены шесть предоставленных pixel-art фонов боя; PNG оптимизированы в WebP без включения исходных тяжёлых копий в проект.
- Фон выбирается стабильно по типу/локации боя и не влияет на simulation.
- Поверх фона остаётся затемняющий tactical veil, lane bands и контрастные маркеры, поэтому фон не ухудшает читаемость.
- Battle scrubber имеет 44px touch-area и 28px thumb для реального использования пальцем.
- Previous / play-pause / next / speed controls получили мобильные touch-targets.

## Save migration

Save v16 → v17 добавляет `campaign.factionCapitalCityIds`. Столицы старого сейва восстанавливаются детерминированно из исходного владения городами и сохранённого порядка extension-карты.

## Проверки

- Strict TypeScript source check пройден с временными declaration stubs из-за недоступного npm registry; stubs не входят в архив.
- Browser layout validation выполнена на мобильных viewport 360×800, 390×844, 412×915 и 520×900: horizontal overflow отсутствует, основные кнопки ≥44px, карта получает 500–640px высоты в тестовых состояниях.
- Отдельно проверен battle layout: scrubber 44px, playback controls 44px, фон остаётся читаемым под tactical overlay.
- `Math.random()` не добавлялся в core/data/simulation.
