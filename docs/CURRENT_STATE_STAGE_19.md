# Корень Живознания — состояние проекта после Stage 19

## Контрольная точка

Игра имеет полный минимальный campaign loop и локально сохраняемую кампанию: выбор лидера → исследование и захват карты → события/образцы/артефакты → конкурирующая экспедиция → Корень → победа/поражение → Continue после перезапуска.

## Карта

- 21 узел: 14 городов, 6 POI и Корень;
- увеличенное пространство Stage 18;
- zoom/pan и центрирование;
- camera position сохраняется в autosave UI snapshot;
- карта больше не обрезается снизу из-за oversized `world-map min-height`;
- портрет выбранного лидера остаётся маркером армии;
- обычное перемещение и выдвижение на штурм используют трёхкадровую walking-анимацию.

## Штурм

При атаке соседнего города:

- core-команда `attackCity()` рассчитывает результат первой;
- React проигрывает walking-переход к целевому узлу;
- затем показывает Battle Viewer либо завершает бескровное занятие;
- при поражении итоговая позиция армии берётся только из рассчитанного core-state.

## Конкурент

Seeded RNG каждой новой кампании выбирает Госпол / Роспол / ИСПУ / Соцпсих / Истотер и случайного невыбранного персонажа-лидера. Конкурент сохраняет traits своего лидера и способен самостоятельно выиграть гонку за Корень.

## Орсия и её командующие

Активны 4–5 из пяти союзных внутренних групп Орсии:

- Орки — Моркогоркид;
- Гоблины — Тонкий Нечеловек;
- Нацболы — Лимоненко;
- Тираниды — Дитя супа в столовой ГУМа;
- ФГУшники — Темный Декан.

Портреты Нацболов и ФГУшников приведены к актуальному соответствию.

## Сохранения Stage 19

- `GameState` save format: **v10**;
- основной autosave в localStorage;
- один резерв предыдущего отличающегося состояния;
- рабочая кнопка «Продолжить»;
- fallback на резерв при повреждённом основном сейве;
- ручная кнопка «Сохранить»;
- восстанавливаются вкладка, выбранный узел и camera state;
- старые v1–v9 по-прежнему проходят существующую migration chain через `deserializeGame()`.

## Победа и поражение

Сохраняются правила Stage 18:

- требования к Корню: города, образцы, обязательный POI, Корневой Предел, армия и припасы;
- конкурент может забрать Корень первым;
- уничтожение основной армии завершает кампанию поражением;
- итоговый экран показывает статистику.
