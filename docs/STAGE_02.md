# Stage 02 — стратегическое движение и ход

## Реализовано

- ресурсы перенесены в `FactionState`;
- save format поднят до v2;
- миграция save v1→v2;
- функции графа для соседства;
- `moveArmy()` как чистая command/simulation функция;
- расход 6 припасов на один переход в прототипе;
- один переход расходует единственное стратегическое действие хода;
- `endTurn()` увеличивает номер хода и восстанавливает действие;
- `CommandOutcome` для ожидаемых отказов команд;
- SVG-карта показывает соседние маршруты;
- React-панель позволяет выбрать соседний узел, перейти и завершить ход;
- обратная связь UI строится из событий команды;
- тесты графа, движения, ограничения одного действия, припасов, завершения хода и миграции сейва.

## Намеренно не реализовано

- захват нейтрального города;
- бой при входе во вражеский/нейтральный город;
- доходы и содержание;
- восстановление припасов в городе;
- дальние маршруты/BFS-команда движения;
- ИИ;
- события кампании.

На этом этапе армия может войти в нейтральный тестовый город без смены владельца. Это временная граница вертикального этапа: правила входа в незахваченный город появятся вместе с атакой/захватом, а не прячутся внутри `moveArmy()`.
