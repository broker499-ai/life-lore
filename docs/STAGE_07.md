# Stage 07 — первый ИИ-конкурент

## Цель

Превратить одиночную экспансию Stage 06 в настоящую пошаговую гонку двух фракций, не создавая отдельные правила для ИИ.

## Реализовано

### Вторая фракция

Добавлена компания **«Меридиан»** (`meridian-company`):

- собственные деньги и припасы;
- стартовый город `rival-post` — Пост Меридиана;
- полевая армия `rival-main`;
- стартовая позиция на противоположном верхнем краю текущей прототипной карты.

Карта получила новое ребро `rival-post → echo-vault`, поэтому первый естественный маршрут конкурента идёт через Свод Эха к Грибному перекрёстку.

### Action economy стала фракционной

Глобальный `CampaignState.strategicActionSpent` удалён.

Теперь:

```ts
FactionState.strategicActionSpent
```

Каждая фракция независимо имеет одно значимое действие в стратегическом ходу. Это позволяет игроку и ИИ использовать те же команды без специальных bypass-флагов.

`endTurn()` после экономики сбрасывает action budget всех фракций.

### AI evaluation

`core/factions/ai` работает headless и deterministic.

ИИ оценивает только непосредственно соседние узлы и учитывает:

- движение к центральному узлу через BFS-distance;
- налоговую ценность города;
- нейтральный или вражеский статус цели;
- оценку боевой силы атакующего и реального защитника;
- имеющиеся припасы;
- численность своей армии.

Для атаки используется минимальный порог относительной силы. Тактика выбирается по ratio сил:

- заметное превосходство → `assault`;
- умеренное превосходство → `balanced`;
- небольшой недостаток → `flank`;
- пограничный риск → `cautious`.

### ИИ использует существующие команды

`runAiTurn()` не редактирует GameState напрямую для игровых действий.

Он вызывает:

- `attackCity()`;
- `moveArmy()`;
- `recruitAtCity()`.

Бой остаётся тем же `simulateBattle(...)` с тем же `GameState.rng.battles`.

### Базовый найм

Если армия конкурента после потерь падает ниже прототипного целевого размера, найм получает высокий приоритет. ИИ использует предложения текущего контролируемого города и оплачивает их из своей казны.

### End-turn pipeline

UI теперь вызывает `advanceTurn()`:

```text
player finishes turn
→ run AI turn
→ collect income for all factions
→ pay upkeep for all factions
→ increment turn
→ reset faction action budgets
```

Захваченный ИИ город поэтому участвует в его экономике в том же end-turn cycle — симметрично тому, как захваченный игроком город приносит налог после завершения хода.

## Взаимодействие полевых армий

При появлении ИИ обнаружена и устранена старая лазейка Stage 06: после захвата city garrison пуст, потому что город занимает полевая армия. Раньше чужая атака могла счесть такой город незащищённым.

Теперь `attackCity()`:

- ищет в целевом городе вражескую полевую армию;
- использует её roster/morale как защитника;
- при победе атакующего применяет реальные потери защитнику;
- отступает проигравшую полевую армию в ближайший другой контролируемый город через BFS;
- если точки отступления нет, полевая армия удаляется;
- только после этого меняет владельца города.

Это позволяет игроку и ИИ реально сталкиваться за один узел.

## UI

Добавлены:

- отдельный цвет городов «Меридиана»;
- отдельный маркер rival field army;
- компактный race indicator над картой;
- для обеих сторон показываются:
  - число контролируемых городов;
  - численность полевой армии;
  - число рёбер до центрального узла;
- после `Завершить ход` feedback сообщает действие конкурента.

## Save v6

Несовместимое изменение action economy подняло формат до **v6**.

Миграция v5→v6:

- переносит старый global `strategicActionSpent` в faction игрока;
- остальным существующим фракциям ставит `false`;
- удаляет глобальное поле из CampaignState.

Старые v1–v4 также продолжают проходить через цепочку миграций.

## Headless-проверка

Seed 42, первый ход ИИ:

- выбирает `echo-vault`;
- tactic: `assault`;
- score цели: 78;
- захватывает Свод Эха;
- battle RNG cursor: 0 → 8;
- армия конкурента: 24 → 20;
- припасы: 80 → 72;
- после налога двух городов и upkeep деньги: 118 → 140.5;
- после завершения хода action budgets обеих фракций снова `false`.

Многоходовой smoke scenario без действий игрока:

1. захват Свода Эха;
2. неудачный штурм Грибного перекрёстка, армия 20 → 16;
3. найм в Своде Эха, армия 16 → 21;
4. повторный штурм и захват Грибного перекрёстка.

Отдельно проверен конфликт полевых армий: сильная армия «Меридиана» атакует Свод Эха, занятый слабой армией игрока; запускается BattleSimulator, город меняет владельца, а выжившая армия игрока отступает во Внешний пост.
