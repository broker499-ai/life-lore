# CURRENT STATE — Stage 25

Версия: **0.25.0**  
Save format: **v14**

## Что изменилось после Stage 23

Stage 25 добавляет стратегические свойства всем 14 городам без новой системы строительства. Свойства хранятся в `CityDefinition.special` и разрешаются общими функциями `core/cities/cityTraits.ts`.

Реально изменяются:

- налоги;
- стоимость и объём найма;
- эффективность отдыха;
- содержание армий;
- сила защитников отдельных городов;
- стоимость финальной операции у Корня.

AI читает те же effective values, что и игрок. ФГУ-коррупция остаётся persistent `CityState.incomeMultiplier` и корректно комбинируется с локальным налоговым свойством города.

## Карта

Видимый город показывает портрет текущего владельца прямо внутри городской иконки. Для игрока/конкурента используются портреты выбранных лидеров; для Орсии — портрет лидера конкретной группы. Нейтральный город сохраняет обычный городской символ.

Тёплая палитра Орсии теперь разделена:

- Орки — жжёно-оранжевый;
- Гоблины — кораллово-красный;
- Нацболы — малиново-красный;
- Тираниды — розово-малиновый;
- ФГУшники — янтарно-оранжевый.

Игрок остаётся зелёным, конкурирующая экспедиция — синей.

Fog of war остаётся authoritative: portrait текущего владельца не отображается для узла, который лишь `explored`, но не `visible` сейчас.
