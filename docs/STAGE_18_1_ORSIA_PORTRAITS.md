# Stage 18.1 — портреты глав внутренних фракций Орсии

Небольшой визуальный патч поверх Stage 18.

## Реализовано

- Вместо буквенных плейсхолдеров в бою подключены полноценные портреты для всех пяти внутренних групп Орсии:
  - Орки;
  - Гоблины;
  - Нацболы;
  - Тираниды;
  - ФГУшники.
- Портреты хранятся в `public/assets/factions/orsia/` и описываются data-driven через `orsiaSubfactions.ts`.
- Для каждой группы добавлена подпись главы/командующего, показываемая под названием стороны в бою.
- Боевой UI адаптирован под более детальные квадратные портреты: размер увеличен, сохранён pixel-art rendering и компактная мобильная компоновка.
- Буквенный placeholder оставлен только как fallback на случай отсутствующего/неизвестного asset.

## Что не менялось

- BattleSimulator и результат боя;
- GameState и save format v10;
- seeded RNG;
- отношения внутренних групп Орсии;
- карта, снабжение и экономика.

Версия приложения: `0.18.1`.
