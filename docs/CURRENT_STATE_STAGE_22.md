# Корень Живознания — состояние проекта после Stage 22

## Контрольная точка

Кампания остаётся полностью проходимой. Все пять внутренних групп Орсии теперь имеют собственные core/data-driven особенности, а управление текущим городом больше не зависит от открытия его карточки.

## Уникальные группы Орсии

- **Орки** — каждый боевой раунд имеют seeded 32% шанс получить +4–9 морали.
- **Гоблины** — новые гарнизоны в 2–3 раза многочисленнее базовых, но их боевая сила на бойца ×0.45.
- **Нацболы** — минимум 94 стартовой морали и одноразовая реакция на первое поражение игроку.
- **Тираниды** — входящие потери ×0.70 против Натиска и Осторожно.
- **ФГУшники** — захваченные у них города сохраняют множитель налога ×0.60.

Все эффекты идут через `FactionTrait`; BattleSimulator не содержит прямых faction-id веток.

## Города и управление

Карточка выбранного узла теперь информационная. Она показывает описание/характеристики и не содержит команд.

Отдельная внешняя панель действий:

- всегда предлагает отдых/найм, если основная армия фактически находится в своём городе и действие допустимо;
- показывает переход для выбранного соседнего узла;
- показывает тактики и штурм для выбранного врага;
- показывает финальную операцию для Корня;
- не поглощает persistent-кнопку **«Завершить ход»**.

## Экономика ФГУ

`CityState.incomeMultiplier` — новый persistent modifier конкретного города. `collectCityIncome()` умножает базовый налог города на него, затем применяет общие faction modifiers. Коррупционный penalty сохраняется после перезахватов и не стакается повторно.

## Save

- текущий save format: **v13**;
- v12→v13 добавляет `CityState.incomeMultiplier` и недостающие Stage 22 faction traits;
- старые города получают multiplier 1, потому что v12 не хранит историю прежних владельцев;
- существующие v12 гоблинские гарнизоны не меняются задним числом;
- autosave/backup/Continue, fog knowledge, research и faction events сохраняются.

## Проверки Stage 22

- core TypeScript compilation проходит;
- TypeScript compilation UI с локальными React/JSX type stubs проходит;
- standalone runtime smoke ядра подтверждает:
  - seeded ×2–×3 гоблинские гарнизоны;
  - реальный подъём морали через battle RNG;
  - слабость гоблинов через power multiplier;
  - ×0.60 после захвата города ФГУшников;
  - корректный effective income;
  - v13 roundtrip и v12→v13 migration;
- `Math.random()` в `src/core` и `src/data` отсутствует.

Полный `npm test` / `npm run build` требует установленных npm dependencies. Если registry недоступен, эти две проверки заменяются описанными локальными TypeScript/runtime smoke checks.
