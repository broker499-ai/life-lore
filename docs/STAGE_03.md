# Stage 03 — Города, экономика и web deployment

## Реализовано

- CityDefinition отделён от CityState: состояние хранит только изменяемое владение, data-файл — налог, отдых и предложение найма.
- Единственный источник истины о владении — `CityState.ownerFactionId`; дублирующий `FactionState.controlledCityIds` удалён.
- Автоматический налог при `Завершить ход`.
- Отдых в своём городе: восстановление припасов и морали до caps.
- Базовый найм-заглушка: пачка пехоты увеличивает `ArmyState.totalUnits` и списывает деньги.
- Отдых и найм расходуют одно стратегическое действие хода.
- Availability API для движения, отдыха и найма: UI не дублирует правила simulation layer.
- Save v3 + миграции v1→v3 и v2→v3.
- Карта получила условные биомы, городские знаки, отображение владения, отдельный знак Корня и маркер экспедиции.
- `netlify.toml`, SPA redirect, web manifest, service worker и PWA icons.

## Временные ограничения

- Нейтральные города всё ещё можно посещать без боя, но их городские действия заблокированы. Это будет заменено системой атаки/захвата.
- Найм пока увеличивает только `totalUnits`; состав армии по типам появится на этапе юнитов.
- Налоги — простые фиксированные числа без стабильности и модификаторов.
- Service worker — минимальный app-shell/offline fallback, не финальная стратегия кэширования.

## Прототипные числа

- Внешний пост: +12 денег/ход.
- Отдых: +20 припасов, +15 морали, caps 100/100.
- Найм: 5 пехотинцев за 30.
- Переход: 6 припасов.
