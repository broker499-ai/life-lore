A headless balance simulator is now part of the repository.

Primary user workflow:

1. double-click `SIMULATE_BALANCE.bat`;
2. wait for the run to finish;
3. read `simulation-results/latest-summary.md`;
4. open `latest-runs.csv` in Excel when deeper analysis is needed.

The simulator runs real core game mechanics with five automated play styles and deterministic seeds. It does not automatically change balance coefficients.
