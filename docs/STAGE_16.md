# Stage 16 — внутренняя Орсия и лидеры экспедиции

Stage 14–15 сознательно пропущены по решению пользователя. Этот этап объединяет внутренние фракции Орсии и ранее запланированную систему лидеров.

## Орсия

В пользовательских текстах страна теперь называется **Орсия** с одной `с`.

Внутри сверх-фракции `orsia` существует пять возможных групп:

- Орки;
- Гоблины;
- Нацболы;
- Тираниды;
- ФГУшники.

При создании новой кампании campaign RNG выбирает 4 или 5 групп. Все исходно орсийские города перемешиваются seeded RNG и распределяются между активными группами; каждая активная группа сначала гарантированно получает хотя бы один город.

Группы имеют отдельные `FactionState.id`, но общий `superFactionId = "orsia"`. `areFactionsAllied()` и `areFactionsHostile()` являются единственной базой для отношений: две внутренние группы Орсии не являются допустимыми целями атаки друг для друга и могут пользоваться союзными узлами при будущих армиях.

## Лидеры

### Артемиос — «Артем есть Артем»

Trait: `ignore_supply`.

- move/attack supply cost = 0;
- supply status = `ignored`;
- morale pressure от разрыва снабжения = 0.

### Владос — «Исследователь заброшек»

Trait: `artifact_effect_multiplier = 1.5`.

Артефактов в текущем билде ещё нет, но универсальный selector уже возвращает коэффициент ×1,5.

### Илиеш — «Картограф»

Trait: `map_revealed`.

Сейчас карта и так открыта полностью. При появлении fog-of-war trait будет служить исключением, раскрывающим всю карту с начала партии.

### Лайош — «Гребец хлебец»

Trait: `river_double_move`, `everyTurns = 3`.

На ходах 3, 6, 9... после обычного первого перемещения разрешается ещё одно перемещение. Второй переход по-прежнему проходит по соседнему ребру и оплачивает собственную стоимость припасов. Атака/найм/отдых не превращаются в двойное действие.

### Максон — «Бассбустед»

Trait: `morale_damage_inflicted_multiplier = 1.25`.

Каждая атака армии Максона умножает наносимое противнику падение морали на 1,25. Боевой RNG и casualty math не меняются.

## UI

- Leader Select показывает пять карточек и полное описание навыка.
- Новая игра создаётся только после выбора лидера.
- Случайный seed берётся из времени старта кампании; повторяемость сохраняется, поскольку сам seed и RNG state входят в GameState.
- В campaign toolbar показывается лидер и текущий статус способности.
- Города Орсии имеют разные цвета по внутренней группе.
- При выборе города location dock показывает `Орсия · <группа>`.
- Для Артемиоса UI прямо показывает, что припасы не требуются.

## Save v8

GameState расширен:

- `FactionState.superFactionId`;
- `FactionState.traits`;
- `FactionState.lastStrategicAction`;
- `FactionState.leaderAbilityLastUsedTurn`.

Миграция v7→v8:

- старый prototype leader заменяется на безопасный текущий default;
- захваченные игроком/Меридианом города сохраняют владельца;
- бывшие нейтральные города получают seeded владельцев Орсии;
- player/rival money/supplies/action budget сохраняются;
- внутренние группы создаются из current defaults.

## Проверки

Добавлены тесты:

- seeded распределение 4–5 внутренних групп;
- минимум один город каждой активной группе;
- союзность групп Орсии и запрет междоусобной атаки;
- игнорирование припасов Артемиосом;
- future traits Владоса/Илиеша;
- второй ход Лайоша только раз в каждый третий ход;
- усиленный первый morale hit Максона;
- save v8 round-trip и legacy migrations.
