# CURRENT STATE — Stage 26

## Артефакты

Артефакты больше не являются одноразовыми ресурсными наградами. Каждый предмет имеет data-driven постоянные modifiers. В коллекции может быть сколько угодно предметов, но одновременно работают максимум три.

Первые свободные слоты заполняются автоматически при находке. Комплект можно бесплатно менять в собственном городе; стратегическое действие не расходуется. Владос усиливает численные эффекты активных артефактов ×1,5.

POI теперь строго предлагают `артефакт ИЛИ образцы`: артефактный вариант не скрывает внутри дополнительные specimen rewards.

## Образцы и Корень

`resources.specimens` — расходуемая исследовательская валюта. `FactionState.specimensCollected` — накопленная научная готовность и не уменьшается после исследований.

Для финальной операции игроку базово нужно собрать **6 образцов за кампанию**. Остаток на руках неважен. «Сигнал Корня» после первого исследования аномалий стоит 2 образца и снижает порог 6 → 4.

## Netlify

Stage 25 действительно не собирался на Netlify из-за отсутствующих Vite/Node TypeScript declarations. Stage 26 добавляет `vite/client`, `@types/node`, Node types для vite.config и фиксирует Node 22.12.0 для Netlify. Команда и директория деплоя остаются стандартными: `npm run build` → `dist`.
