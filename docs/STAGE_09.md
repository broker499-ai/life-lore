# Stage 09 — Animated Battle Playback

## Цель

Превратить Battle Viewer из ручного просмотрщика кадров в автоматически проигрываемый «матч» в духе Football Manager, не меняя математическую боевую систему.

## Реализовано

- бой автоматически стартует при открытии Battle Viewer;
- play/pause;
- скорости ×1 / ×2 / ×4;
- предыдущий/следующий кадр с автоматической постановкой на паузу;
- scrubber также ставит просмотр на паузу;
- `Пропустить` мгновенно переводит к финальному кадру;
- с финального кадра можно повторить проигрывание;
- длительность визуальных кадров сжимает simulation time и ограничена сверху, поэтому крупные битвы не превращаются в многоминутное ожидание;
- плавное перемещение формаций между presentation frames;
- небольшое детерминированное «живое» движение точек без RNG;
- visual pressure shift по уже рассчитанным combat rolls / casualties;
- потерянные маркеры плавно гаснут вместо мгновенного удаления;
- импульс и кольцо потерь при casualty frame;
- `prefers-reduced-motion` отключает autoplay и декоративные анимации;
- визуализация по-прежнему не меняет `BattleResult`, RNG или `GameState`.

## Локальный запуск

Добавлен `START_GAME.bat`.

При двойном клике он:

1. проверяет Node.js/npm;
2. при первом запуске выполняет `npm install`;
3. запускает Vite на фиксированном `http://localhost:5173`;
4. автоматически открывает браузер.

После первого успешного `npm install` интернет для обычного локального запуска не требуется, кроме внешних ресурсов, если они когда-либо появятся в будущем.

## Проверка

- весь `src` проходит TypeScript-проверку через локальный компилятор с временными декларациями React;
- pure playback helper исполнен отдельно;
- для тестового перехода задержки составили 660 / 330 / 165 ms на ×1 / ×2 / ×4;
- длинный simulation gap ограничен 1200 ms на ×1;
- npm/Vitest в текущей среде не запущен, потому что доступ к registry зависает; это ограничение среды, не успешно пройденный тест.
