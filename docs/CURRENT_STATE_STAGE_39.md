# Current state — Stage 39

Версия приложения: **0.39.0**  
Save format: **v21**

Текущий научный цикл: события/артефакты → **Познание Орсии 0–12** → финальный допуск при 8/12. Отдельной вкладки исследований нет. Познание не расходуется.

Артефакт в POI всегда является реальной альтернативой более крупному приросту Познания: сам артефакт даёт +1 Познания, но также слегка подкрепляет часть вражеских городских гарнизонов. Городские посещения больше не выдают артефакты.

На 25% и 75% шкалы Познания интерфейс/карта получают два уровня визуального заражения. Боевой экран дополнительно показывает крупные драматические события, screen-kick, shockwave и редкие брызги крови.
