# Current state — Stage 45

Version: **0.45.0**  
Save format: **v23**

Battle 3.0 now uses reactive direct manipulation rather than a limited list of command buttons. Enemy lanes telegraph assault/rest/cautious behavior, local defender strength and morale are seeded-randomized, player lanes can deep-defend or attack matching/adjacent enemy lanes with a 1-second cooldown, victorious player lanes rest automatically, and local lane collapse remains independently possible through the panic die.

Player-side pre-battle lane customization is intentionally reserved for the next battle iteration.
