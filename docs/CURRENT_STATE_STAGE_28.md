# Current state — Stage 28

Build: `0.28.0`  
Save: `v16`

Кампания теперь состоит из двух последовательных географических фаз. Первая сохраняет прежнюю разветвлённую карту. «Корень Живознания?» в её центре является ложной целью — зрительным корнем. После одноразового события открывается вторая, линейная часть из восьми новых городов и семи POI в seeded-случайном порядке, после которой расположен настоящий Корень Живознания.

Профком и Линьхао имеют владения только во второй части. Профком наследует коррупционную механику ФГУ; Линьхао защищает каждый свой город одним сверхсильным юнитом.

Все POI из нового документа перенесены с их вариантами, артефактами, образцами, моралью и расходами. Финальная операция использует последний случайно выбранный город линейного маршрута как staging city.
