# Current state — Stage 46

**Build:** 0.46.0  
**Save:** v24

Current combat is Reactive Battle 3.1: enemy lanes telegraph assault, rest and cautious combat directly on the battlefield. Rest is shown by an actual retreat into the enemy half; player pressure interrupts it and produces the visible state «ОТДЫХ НАРУШЕН». Player deep defense and attack directions are represented by large tactical glyphs/arrows rather than separate command buttons.

Recruitment is a free secondary action and no longer consumes the turn's strategic action. Unique-unit cities advertise themselves through the glowing recruitment button.

New unique unit **Глеб Хлеб** occupies a lane by himself, has combat weight of roughly 50 basic troops and an unbreakable 100 morale lane while alive.
