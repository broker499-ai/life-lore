# Корень Живознания — состояние проекта после Stage 23

## Контрольная точка

Версия приложения: **0.23.0**.

Save format: **v14**.

Кампания сохраняет весь Stage 22: фракционные traits, fog of war, исследования, autosave/backup, конкурентную экспедицию, supply, бой, city-action UX и финальную операцию.

## Карта и контент

Актуальные 21 точки соответствуют приложенной таблице Stage 21 по названиям, типам, описаниям и шести одноразовым POI-событиям.

Особенно важно:

- Убежище 103 заменяет прежний пользовательский «Тихий Крик»;
- Неестественные джунгли заменяют прежнюю «Временную заставу»;
- Корень больше не раскрывает кафе в описании;
- Канцелярские Копи остаются стартовым городом конкурента, но имеют актуальный текст;
- topology/internal ids сохранены ради сейвов.

## Артефакты

Шесть POI-находок:

- Скелет яблока;
- Фляга совершенно нормального сока;
- Убойнастойка;
- Красная редиска;
- Ванильный хрящ;
- Почти-трава.

Дополнительно каждый город имеет один одноразовый артефакт за фактическое посещение. Для этого используется `campaign.cityArtifactClaimedIds`. Владос усиливает все artifact effects единообразно.

## Убежище 103

После захвата город предлагает стандартную пехоту и уникальных **Студентов 103** — ranged-юнит сильнее обычных следопытов.

## Директивы с поверхности

`SurfaceBriefing` — отдельный сериализуемый story layer, не связанный с BattleSimulator.

Пять обычных сообщений идут последовательно по прогрессу кампании; первое требует хотя бы один артефакт. Шестое ставится вручную в pending при попытке открыть финальную операцию у Корня и должно быть подтверждено до появления финального выбора.

## Save v14
