# Stage 26 — артефакты, научный допуск к Корню и Netlify build fix

Версия приложения: **0.26.0**  
Save format: **v15**

Stage 26 разводит две исследовательские награды по разным функциям: артефакты теперь формируют постоянный билд экспедиции, а образцы остаются расходуемой валютой исследований и одновременно учитываются как накопленный научный прогресс для допуска к Корню.

## Артефакты

- найденный артефакт больше не выдаёт одноразовые деньги, припасы, мораль или образцы;
- каждый артефакт даёт постоянный стратегический/боевой modifier;
- коллекция не ограничена, но одновременно активны максимум **3 артефакта**;
- первые три найденных артефакта автоматически занимают свободные слоты;
- последующие складываются в коллекцию без автоматического эффекта;
- менять комплект можно бесплатно, только когда основная армия находится в контролируемом городе;
- смена комплекта не расходует стратегическое действие;
- Владос по-прежнему усиливает численные эффекты артефактов ×1,5. Для multiplier-эффекта усиливается отклонение от 1.0: например +18% превращается в +27%, а −18% — в −27%.

Артефактные traits добавляются к `FactionState.traits` с сериализуемым `source: artifact:<id>`. Это позволяет общим faction trait resolver'ам учитывать артефакты без проверок конкретного artifact id в бою, экономике или снабжении.

### Редкие POI-артефакты

- **Скелет яблока** — доход городов +18%;
- **Фляга совершенно нормального сока** — стоимость припасов стратегических действий −18%;
- **Убойнастойка** — потери морали −16%, наносимый урон морали +8%;
- **Красная редиска** — боевая сила армии +14%;
- **Ванильный хрящ** — боевая сила +9%, содержание армии −8%;
- **Почти-трава** — стоимость финальной операции −25%.

Городские артефакты слабее и дают небольшие специализирующие бонусы к доходу, upkeep, снабжению, боевой силе, морали или финальной операции.

## Артефакт ИЛИ образцы

В POI выбор теперь строго взаимоисключающий:

- вариант с артефактом выдаёт артефакт и только явно указанные штрафы/побочные эффекты события;
- вариант с образцами выдаёт образцы;
- свойства самого артефакта никогда не добавляют образцы.

Например, в поликлинике вход в кабинет −260 всё ещё даёт `Убойнастойку` и −3 морали, но не образцы. Исследование коридора даёт +2 образца и −2 морали, но не артефакт.

## Образцы и научная готовность

У фракции теперь есть два связанных показателя:

- `resources.specimens` — текущий расходуемый запас;
- `specimensCollected` — сколько образцов было получено за кампанию всего.

Исследование уменьшает только текущий запас. Накопленный показатель не уменьшается.

Базовый доступ игрока к Корню теперь требует **6 изученных/собранных за кампанию образцов**, а не 6 оставшихся на руках. Поэтому игрок не наказывается за расход образцов на исследования.

Исследование **«Сигнал Корня»** теперь стоит 2 образца после «Административного резонанса» и снижает требование научного допуска с **6 до 4**. Таким образом, ветка действительно создаёт ранний научный маршрут к финалу: её суммарная стоимость равна 4 образцам.

UI у Корня показывает `Научная готовность X/Y`, а лаборатория отдельно показывает запас и количество собранных за кампанию образцов.

## Save v15

Добавлены сериализуемые поля:

- `FactionState.specimensCollected`;
- `CampaignState.activeArtifactIds`.

Миграция **v14 → v15**:

- восстанавливает исторически собранные образцы как текущий остаток + стоимость уже завершённых исследований Stage 21;
- использует старую стоимость `Сигнала Корня` = 4 при реконструкции legacy-save;
- автоматически активирует первые три уже найденных артефакта;
- пересобирает artifact traits с учётом способности Владоса;
- сохраняет поддержку всех предыдущих миграций.

## Исправление Netlify

Ошибка Stage 25 была реальной TypeScript-конфигурационной проблемой, а не проблемой publish directory. Исправлено:

- добавлен `src/vite-env.d.ts` с `vite/client`;
- `vite/client` явно добавлен в `tsconfig.app.json`;
- добавлен `@types/node`;
- `types: ["node"]` добавлен в `tsconfig.node.json`;
- Node зафиксирован на **22.12.0** в `.nvmrc` и `netlify.toml`;
- в `package.json` добавлен Node engine `>=22.12.0`.

Это закрывает ошибки:

- `Property 'env' does not exist on type 'ImportMeta'`;
- `Cannot find module 'node:url' or its corresponding type declarations`;
- `Property 'url' does not exist on type 'ImportMeta'`.

Build command остаётся `npm run build`, publish directory — `dist`.
