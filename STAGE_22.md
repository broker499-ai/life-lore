# Stage 22 — оставшиеся особенности Орсии и действия вне карточки города

Stage 22 завершает первый набор уникальных механик всех пяти внутренних групп Орсии и упрощает управление городом. Боевые и экономические эффекты остаются data-driven, а карточка выбранной локации больше не служит контейнером команд.

## 1. Орки — случайный подъём морали

Орки получили faction trait `random_battle_morale_gain`:

- в конце каждого боевого раунда есть **32%** шанс боевого подъёма;
- прибавка составляет **4–9 морали**;
- morale не превышает общий cap 100;
- шанс и величина используют существующий seeded battle RNG.

BattleSimulator не проверяет `orsia-orcs`. Он получает универсальную настройку эффекта через battle-side input.

## 2. Гоблины — толпа слабых бойцов

Гоблины получили два универсальных trait:

- `initial_garrison_size_multiplier_range`: при создании новой кампании каждый их стартовый городской гарнизон получает seeded множитель численности **×2.00–×3.00**;
- `battle_unit_power_multiplier`: вклад каждого гоблинского бойца в боевую силу равен **×0.45** обычного.

Множитель силы применяется и к раундовым attack/defense calculations, и к final-strength resolution, поэтому большое число гоблинов не превращается обратно в обычную армию при достижении лимита раундов.

Численность генерируется только при старте новой кампании. Уже существующие v12 гарнизоны при миграции не раздуваются задним числом.

## 3. ФГУшники — коррупционный след города

ФГУшники получили trait `captured_city_income_multiplier` со значением **0.60**.

При захвате города, которым владели ФГУшники:

- город переходит победителю как обычно;
- в `CityState` сохраняется `incomeMultiplier = 0.60`;
- налог этого города после захвата составляет только **60%** базовой величины;
- штраф принадлежит городу и сохраняется при последующих сменах владельца;
- повторный захват не умножает штраф ещё раз.

Экономика читает этот modifier в core; UI лишь показывает эффективный налог и пометку о коррупции.

## 4. Карточка локации стала информационной

При нажатии на город/POI карточка теперь показывает только информацию:

- название и описание;
- владельца;
- налог и последствия коррупции;
- гарнизон, если его можно видеть;
- параметры отдыха;
- supply context;
- уникальную характеристику орсийской фракции;
- требования Корня, если выбран центральный узел.

Командных кнопок внутри этой карточки больше нет.

## 5. Внешняя панель стратегических действий

Добавлен отдельный `StrategicActionBar` под информационной карточкой:

- **Отдохнуть** и **Найм** вычисляются по фактическому текущему городу армии и доступны без выбора этого города;
- **Перейти** доступен для выбранной допустимой соседней цели;
- **Атаковать / Занять** и выбор тактики доступны для выбранного враждебного города;
- **Финальная операция** доступна при выборе Корня и выполнении требований;
- **Завершить ход** остаётся отдельной постоянной кнопкой вне карточки и вне action bar.

Таким образом, выбор города отвечает за инспекцию/выбор цели, а не за открытие базовых городских команд.

## 6. Save v13

`CityState` получил persistent `incomeMultiplier`, поэтому save format повышен **v12 → v13**.

Миграция v12→v13:

- добавляет всем старым городам `incomeMultiplier = 1`;
- подключает отсутствующие Stage 22 traits активным Оркам, Гоблинам и ФГУшникам;
- не меняет уже существующие гарнизоны старой кампании;
- сохраняет все research/faction-event/fog/autosave данные Stage 21.

Исторического прежнего владельца уже захваченного города в v12 восстановить невозможно, поэтому коррупционный штраф появляется для новых захватов ФГУшников после миграции.

## 7. Архитектурные ограничения

Сохранены:

- seeded RNG и отдельный battle RNG stream;
- отсутствие `Math.random()` в simulation/data layer;
- один сериализуемый `GameState`;
- BattleSimulator не знает id Орков/Гоблинов/ФГУшников;
- economy/core, а не React, определяет размер дохода;
- UI не определяет исход боя и не применяет игровые эффекты самостоятельно;
- `START_GAME.bat`, Vite/PWA/Netlify workflow не менялись.
