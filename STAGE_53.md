# Stage 53 — финальная катсцена, DEV-телепорт, ускорение боя

Версия: **0.53.0**  
Save format: **v25** (структура `GameState` не менялась).

## Финальная катсцена Корня

- Старый диалог `Финальная операция` заменён полноценной последовательностью поверх игры.
- При запуске операции сначала показывается `public/assets/finale/root-tree.png`.
- Через 1 секунду появляется строка: `Наконец-то... Живознание здесь...`.
- Затем изображение плавно crossfade-переходит в `root-in-hands.png`.
- На втором изображении появляется финальный монолог и два выбора:
  1. **Принять Корень** — завершает кампанию через существующую победную ветку; индивидуальные концовки лидеров оставлены для следующего этапа.
  2. **Положить Корень в судочек и вернуться домой** — доступно только при максимальном Познании Орсии (`12/12`).
- Второй выбор плавно переводит сцену на `root-cafe.png`; через 2 секунды появляется рекламная надпись Корень-кафе и кнопка завершения кампании.
- Все три изображения предзагружаются одновременно внутри overlay, переходы сделаны через opacity/scale transitions без резких смен кадров.
- Старое обязательное промежуточное срочное сообщение с поверхности больше не перехватывает запуск финальной операции.

## DEV-телепорт

- В режиме разработчика при выборе любой точки карты появляется действие **`DEV · Телепорт`**.
- Телепорт не расходует стратегическое действие и сразу переносит основную армию в выбранный узел.
- Точка помечается разведанной; если у неё есть location-event, он запускается как при обычном прибытии.
- Работает и с глубокой Орсией, которая уже раскрывается DEV-режимом.

## Бой

- Блок `×1 / ×2 / ×4 / Пропустить` вынесен из нижней playback-панели.
- В landscape он теперь является первой строкой правого rail: прямо под правой стороной/флангом и над описанием текущего этапа/события.
- Для коротких 16:9 экранов добавлены отдельные компактные размеры.

## Проверки

- Полный TypeScript-граф приложения проверен глобальным TypeScript 5.8.3 с временными декларациями отсутствующих внешних npm-пакетов — без ошибок.
- Реальный `npm run typecheck` не может стартовать полноценно без установленных `vite/client` и `@types/node`; зависимости в релизный ZIP не включаются.
- Runtime-smoke DEV-телепорта: защита без DEV, перенос на `true-root-sanctum`, раскрытие точки, отсутствие расхода действия — пройден.
- `GameState` не менялся, поэтому migration/save bump не требуется.
