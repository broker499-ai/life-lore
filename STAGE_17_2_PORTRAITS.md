# Stage 17.2 — портреты лидеров

> Историческая заметка: временная оранжевая подложка этого этапа удалена в Stage 17.3.

Добавлены реальные pixel-art портреты пяти лидеров.

- Фоны исходных PNG очищены программно и сохранены с alpha transparency.
- На экране выбора лидера вместо буквенных заглушек показываются портреты.
- На стратегической карте маркер основной армии игрока заменён круглым портретом выбранного лидера.
- Под портретами временно используется ярко-оранжевая подложка `#ff7a00` для визуальной проверки прозрачности. Если вокруг силуэта виден оранжевый цвет, фон PNG действительно прозрачный.
- Игровое ядро, RNG, снабжение, бои и save format не изменялись.

После подтверждения пользователем оранжевую debug-подложку можно заменить на финальную стилизацию маркера.

## Проверки

- PNG-файлы декодируются, alpha channel содержит реальные прозрачные пиксели.
- Отдельный оранжевый preview подтверждает отсутствие белого/серого checkerboard вокруг силуэтов.
- `src/core` побайтно не изменён относительно Stage 17.1.
- Все локальные `@/` импорты разрешаются.
- Полный `npm install/build/test` в текущем sandbox не завершён: доступ к npm registry зависает, поэтому сборка не помечается как полностью проверенная через Vite/Vitest.
