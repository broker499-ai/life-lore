# Корень Живознания — Stage 16

Portrait-first стратегическая RPG. К Stage 16 браузерный прототип содержит расширенную соревновательную кампанию и автоматически проигрываемые бои: после штурма математический BattleSimulator выдаёт результат/timeline, а React/SVG показывает его как короткий матч с движущимися точками-отрядами в духе Football Manager.

## Карта Stage 12

- 21 узел: 14 городов, 6 точек интереса и Корень Живознания;
- несколько альтернативных маршрутов от периферии к центру;
- каждый узел имеет собственное описание;
- новые локации включают Подвал поликлиники 202, Великие хранилища столовой, Подфонтанье, Секретные этажи физфака, Клуб Клуб и Фаланстер;
- POI проходятся как обычные узлы и визуально отличаются от городов;
- городской UI теперь map-first: компактный dock + горизонтальная строка действий, поэтому найм больше не съедает половину карты.

Подробно: `docs/STAGE_12.md`.


## Снабжение и камера Stage 13

- снабжение вычисляется от ближайшего контролируемого города по реальной линии графа;
- чужие и нейтральные города не могут ретранслировать снабжение;
- дальние действия дорожают: 100/85/65/40/10–20% supply status;
- растянутая и отрезанная армия получает давление на мораль в конце хода;
- AI использует те же supply-adjusted movement/attack costs;
- активная линия снабжения подсвечивается на карте;
- камера карты: 100/135/175/220%, колесо, кнопки, перетаскивание и центрирование на экспедиции;
- location dock теперь имеет собственную вертикальную прокрутку, полный текст описаний и постоянно доступную горизонтальную полосу действий;
- описание Подвала поликлиники 202 исправлено: поликлиника всё ещё работает — на горе каждому.

Подробно: `docs/STAGE_13.md`.


## Фракции Орсии и лидеры Stage 16

- название страны нормализовано: **Орсия** — в пользовательских текстах везде одна `с`;
- внутренние группы: Орки, Гоблины, Нацболы, Тираниды и ФГУшники;
- при старте кампании seeded RNG выбирает 4 или 5 групп и случайно распределяет между ними все орсийские города;
- каждая активная группа гарантированно получает минимум один город;
- все внутренние группы имеют `superFactionId = orsia`, считаются союзниками и базовые команды запрещают им атаковать друг друга;
- их города различаются цветом, а карточка локации показывает конкретного владельца;
- выбор лидера теперь настоящий: Артемиос, Владос, Илиеш, Лайош, Максон;
- Артемиос: движение/штурм не расходуют припасы, supply pressure не действует;
- Владос: коэффициент эффекта артефактов ×1,5 уже заложен для будущей системы;
- Илиеш: trait полного знания карты уже заложен для будущего тумана войны;
- Лайош: каждый 3-й ход после первого перемещения доступен второй переход;
- Максон: наносит ×1,25 урона по морали противника;
- новая кампания получает случайный seed из времени запуска, поэтому распределение Орсии меняется между партиями;
- save format: **v8**, старые v1–v7 мигрируют автоматически.

Подробно: `docs/STAGE_16.md`.

## Что можно сделать в интерфейсе

1. Главное меню → выбрать одного из пяти лидеров с уникальным навыком.
2. Выбрать соседний нейтральный/чужой город и увидеть защитников.
3. Выбрать тактику и провести deterministic штурм.
4. Получить реальные потери/мораль, захватить город или отступить.
5. Отдыхать и нанимать два типа войск в своих городах.
6. Просматривать roster, атаку, защиту, мораль и upkeep.
7. Завершить ход — после этого **ИИ делает своё действие**, затем начисляются налоги и содержание.
8. Постоянно видеть на карте армию конкурента, его города и race indicator: число городов, размер армии и расстояние до центра.

## Боевой Viewer Stage 11

- отдельный экран боя после настоящего штурма;
- три сектора боя: левый фланг / центр / правый фланг;
- передняя линия и отдельная задняя линия стрелков;
- точный roster по типам войск отражается в составе визуальных маркеров;
- автоматическое проигрывание presentation frames;

- непрерывное движение формаций и отдельное давление по каждому сектору;
- тактики визуально меняют геометрию строя: натиск давит центром, осторожная держит глубину, обход ускоряет фланги;
- SVG-залпы и короткие векторы атак/контратак;
- потерянные точки гаснут, свежие потери получают импульс;
- численность, мораль, потери, тактика и условное время;
- scrubber для ручного перехода в любую точку боя;

- внешние графические ассеты не требуются.

## ИИ Stage 07

- отдельная фракция `meridian-company`;
- своя казна, припасы, стартовый город и полевая армия;
- одно стратегическое действие на фракцию за ход;
- оценивает только соседние цели;
- учитывает налоговую ценность, риск боя и прогресс к центральному узлу;
- выбирает тактику по соотношению сил;
- использует **те же** `attackCity`, `moveArmy`, `recruitAtCity` и BattleSimulator, что игрок;
- при серьёзных потерях приоритетно пополняет армию;
- deterministic при одинаковом GameState + RNG.

Если полевая армия стоит в атакуемом городе, она теперь является реальным защитником. При поражении защитник отступает в ближайший контролируемый город; захват «поверх» вражеской армии невозможен.

Подробно: `docs/STAGE_07.md`.

## Запуск локально

### Windows — самый простой способ

Дважды нажать **`START_GAME.bat`** в корне проекта.

BAT сам проверит Node.js/npm, при первом запуске установит зависимости, запустит `localhost:5173` и откроет браузер. Для первого запуска нужен интернет. Требуется Node.js 20.19+ или 22.12+ (или новее).

### Вручную

```bash
npm install
npm run dev
```

Production build:

```bash
npm run build
npm run preview
```

Тесты:

```bash
npm test
```

TypeScript:

```bash
npm run typecheck
```

## Архитектурные правила

- `src/core/**` — единственный источник игровых правил.
- React — presentation/UI; стратегическая карта — SVG.
- Боевой timeline автоматически проигрывается через read-only BattlePresentation + React/SVG; scheduler/анимации не имеют доступа к GameState или RNG; Phaser остаётся опциональным будущим renderer.
- RNG seeded и разделён на campaign/battles/events.
- игрок и ИИ используют одинаковые базовые команды.
- стратегическое действие хранится **на уровне FactionState**, а не глобально.
- текущая версия сейва — **v8**.
- `ArmyState.roster` и `CityState.ownerFactionId` остаются единственными источниками истины своих сущностей.

Подробнее: `ARCHITECTURE.md`, `docs/DECISIONS.md`, `docs/COMBAT_VISION.md`, `docs/STAGE_08.md`.
