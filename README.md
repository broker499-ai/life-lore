# Корень Живознания — Stage 25

> **Stage 25 · Уникальные города и визуальная принадлежность карты.** Все 14 городов получили data-driven стратегические свойства: налоги, найм, отдых, содержание, оборона или влияние на финальную операцию. AI использует те же effective values. Пять групп Орсии получили различимые красно-оранжево-розовые цвета, а на видимых городских узлах отображаются портреты текущих владельцев. Save format остаётся v14, потому что GameState не расширялся. Подробнее: `docs/STAGE_25.md`, `docs/CURRENT_STATE_STAGE_25.md`.

Игровое ядро, save v9 и симуляция не менялись. Подробнее: `docs/STAGE_17_DESIGN_UPDATE.md`.

Игровое ядро и save v9 не менялись; animation state существует только в React/SVG presentation layer. Подробнее: `docs/STAGE_17_3_CHARACTERS.md`.

## Фракции Орсии и лидеры Stage 16

- Stage 18 поднял save format до v10; Stage 20 — до v11 для fog knowledge; Stage 21 — до v12 для исследований и одноразовых faction events; Stage 22 — до **v13** для persistent-модификатора дохода захваченных городов; Stage 23 — до **v14** для городских артефактов и сюжетных директив.

## Что можно сделать в интерфейсе

1. Главное меню → выбрать одного из пяти лидеров с уникальным навыком.
2. Выбрать соседний нейтральный/чужой город и увидеть защитников.
3. Выбрать тактику и провести deterministic штурм.
4. Получить реальные потери/мораль, захватить город или отступить.
5. Отдыхать и нанимать два типа войск в своих городах.
6. Просматривать roster, атаку, защиту, мораль и upkeep.
7. Завершить ход — после этого **ИИ делает своё действие**, затем начисляются налоги и содержание.
8. Разведывать Орсию через fog of war; точная позиция и силы конкурента видны только при наблюдении (Илиеш игнорирует это ограничение).
9. Собирать образцы и тратить их на исследования флоры, фауны и аномалий.
10. Сталкиваться с уникальными свойствами всех пяти внутренних групп Орсии.
11. Выполнить требования Корня и запустить финальную операцию.
12. Полностью выиграть кампанию или проиграть, если конкурент заберёт Корень первым / основная армия будет уничтожена.

## Конкурирующая экспедиция — Stage 18

- internal simulation faction: `rival-expedition`;
- при новой кампании seeded RNG выбирает Госпол, Роспол, ИСПУ, Соцпсих или Истотер;
- организацию возглавляет случайный лидер из четырёх невыбранных игроком;
- его leader traits работают через ту же data-driven систему, что у игрока;
- своя казна, припасы, стартовый город и полевая армия;
- одно стратегическое действие на фракцию за ход;
- AI учитывает налоговую ценность, риск боя, снабжение и прогресс к центру;
- использует **те же** `attackCity`, `moveArmy`, `recruitAtCity` и BattleSimulator, что игрок;
- после выполнения требований способен первым забрать Корень и завершить кампанию поражением игрока.

Если полевая армия стоит в атакуемом городе, она является реальным защитником. При поражении защитник отступает в ближайший контролируемый город; захват «поверх» вражеской армии невозможен.

Подробно: `docs/STAGE_18.md`.

## Запуск локально

### Windows — самый простой способ

Дважды нажать **`START_GAME.bat`** в корне проекта.

BAT сам проверит Node.js/npm, при первом запуске установит зависимости, запустит `localhost:5173` и откроет браузер. Для первого запуска нужен интернет. Требуется Node.js 20.19+ или 22.12+ (или новее).

### Вручную

```bash
npm install
npm run dev
```

Production build:

```bash
npm run build
npm run preview
```

Тесты:

```bash
npm test
```

TypeScript:

```bash
npm run typecheck
```

## Архитектурные правила

- `src/core/**` — единственный источник игровых правил.
- React — presentation/UI; стратегическая карта — SVG.
- Боевой timeline автоматически проигрывается через read-only BattlePresentation + React/SVG; scheduler/анимации не имеют доступа к GameState или RNG; Phaser остаётся опциональным будущим renderer.
- RNG seeded и разделён на campaign/battles/events.
- игрок и ИИ используют одинаковые базовые команды.
- стратегическое действие хранится **на уровне FactionState**, а не глобально.
- текущая версия сейва — **v14**.
- `ArmyState.roster` и `CityState.ownerFactionId` остаются единственными источниками истины своих сущностей.

Подробнее: `ARCHITECTURE.md`, `docs/DECISIONS.md`, `docs/COMBAT_VISION.md`, `docs/STAGE_08.md`.

## События, артефакты и директивы Stage 23

- 6 POI имеют одноразовые data-driven события первого посещения по актуальной таблице карты;
- канонические находки POI: «Скелет яблока», «Фляга совершенно нормального сока», «Убойнастойка», «Красная редиска», «Ванильный хрящ», «Почти-трава»;
- каждый из 14 городов один раз выдаёт собственный временный артефакт при фактическом посещении основной армией;
- «Убежище 103» нанимает «Студентов 103» — усиленный ranged-вариант разведчиков;
- первые пять коротких сообщений с поверхности идут последовательно по прогрессу кампании; первое появляется только после первого артефакта;
- шестое утверждённое сообщение показывается при попытке начать финальную операцию у Корня, до финального выбора;
- артефактные эффекты по-прежнему усиливаются Владосом ×1,5;
- city-visit rewards и narrative state сериализуются и не фармятся повторно.
